# v2.14.0.0 — Forex analysis and a broader research workspace

ChartNagari now supports Forex analysis with keyless Yahoo candles by default
and optional OANDA candle collection. This release also includes guided AI setup,
HTF opportunity tracking, local and remote server profiles, workspace improvements,
and an experimental order plugin developer kit.

## For ICT traders

- Add supported major and cross pairs in Symbols, then inspect New York aligned
  session boxes, Asian range levels, currency strength and DXY context.
- Review FX signals and alerts, and run backtests that report pips with a
  configurable spread assumption. FX order execution is not included.
- Use Yahoo without an API key, or configure an eligible OANDA account for
  candles. `auto` selects OANDA when a token is saved and Yahoo otherwise.
  OANDA v20 API eligibility varies by region and account; a practice account
  alone does not guarantee access.
- Yahoo gold and silver use `GC=F` and `SI=F` futures proxies, identified in
  the interface. DXY is added once for enabled USD pairs; a saved opt-out is
  respected.

## More in this release

- **Guided AI setup:** Choose model presets and local or remote profiles, test
  sample responses, download selected Ollama models and activate the runtime
  explicitly. Laya remains a future typed-decision integration, not a current
  text-generation provider.
- **HTF research:** Backtest exposes a read-only 1H/4H history inventory. New
  pre-filter opportunities and versioned five-day forward outcomes feed a
  read-only ATR-decile performance API. Pending and missing outcomes remain
  distinct from completed returns. These live first-observation samples can
  include unfinished candles; automatic HTF penalty calibration remains off
  and existing scoring is unchanged. See [Issue #32 progress](https://github.com/Ju571nK/ChartNagari/blob/v2.14.0.0/docs/releases/issue-32-progress.md).
- **Server profiles:** Verify and switch between local and remote servers with
  authenticated capability checks. Opt-in remote mode protects API reads and
  browser WebSockets; credentials stay in memory and require reauthentication
  after a reload. Remote exposure requires an HTTPS reverse proxy and careful
  origin configuration. See [connection setup](https://github.com/Ju571nK/ChartNagari/blob/v2.14.0.0/docs/remote-connections.md).
- **Settings and navigation:** Web settings show startup values, pending
  restarts and process states without exposing credentials. Calendar diagnostics
  distinguish waiting, empty and failed collection; calendar and AI settings
  are available where used. Beginner navigation, mobile controls, chart data
  status and backtest guidance have been refined.
- **Order plugin developer kit:** The experimental v1 HTTP contract, Go SDK,
  paper simulator and read-only compatibility checker support adapter
  development. ChartNagari can inspect registered plugin metadata but does not
  route signals through the new order API or enable live trading. See the
  [developer kit](https://github.com/Ju571nK/ChartNagari/blob/v2.14.0.0/docs/order-plugin-kit.md).

## Data and interpretation notes

Yahoo FX has no meaningful volume. OANDA tick volume is not centralized traded
volume. Most pairs use a 0.0001 pip; JPY quotes use 0.01, XAUUSD 0.1 and XAGUSD
0.01. Default spread assumptions are 1 pip for majors, 2 for other supported
crosses and 3 for metals. Backtests subtract spread but omit swap, commissions,
slippage and broker-specific execution. Yahoo daily and weekly candles retain
Yahoo's own alignment and may differ from OANDA New York close bars.

FX backtest entry and exit prices reflect half-spread adjustments on both sides;
TP and SL derive from mid prices. Paper positions retain their entry provider,
environment, instrument mapping and proxy identity. A changed or unknown FX
source suspends evaluation while retaining history. Paper evaluation begins
with the first fully eligible candle after entry. When one candle touches both
TP and SL, backtest and paper retain the optimistic TP-first assumption; the
intrabar sequence is unknown.

A 4H-only backtest cannot derive an exact Asian range. AMD marks it unavailable;
exact range evaluation needs hourly history. Live overlays use 1H data even on
a 4H chart. ICT kill zones and session windows now follow New York daylight
saving time across asset classes, so their UTC firing times change seasonally.

## Upgrade notes

Back up settings and the database before upgrading. Preserve existing
`config/settings.yaml` and watchlists rather than replacing them with examples.
Configure the Forex provider and optional OANDA token in Settings. A provider
transition purges stored FX candles and starts a fresh backfill. OANDA
practice/live selects a market-data environment; it does not enable order
execution. Check the [Forex guide](https://github.com/Ju571nK/ChartNagari/blob/v2.14.0.0/docs/FOREX.md) for regional API eligibility,
provider alignment and cost limitations. Remote mode requires a strong
administrator token, allowed origins and a protected HTTPS reverse proxy.
