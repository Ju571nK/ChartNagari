# DRAFT — v2.14.0.0: Forex analysis and ICT sessions

> Draft release notes for review. This does not announce a published release.

ChartNagari adds Forex as an analysis asset class, with keyless Yahoo candles by
default and optional OANDA candle collection. The scope covers charts, signals,
alerts and backtests; FX order execution is not included.

## Highlights

- Add supported currency pairs from Symbols, including majors and crosses.
- Explore New York aligned session boxes, Asian range levels, currency strength
  and the DXY context panel.
- Read FX backtests in pips with a configurable spread assumption.
- Choose Yahoo or OANDA candles; `auto` selects Yahoo without a saved OANDA
  token and OANDA when one is saved. OANDA eligibility varies by region/account;
  a demo account alone may not qualify. Provider changes purge and backfill FX
  history.
- Yahoo gold and silver symbols use futures proxies (`GC=F`, `SI=F`) and are
  identified as proxies in the interface.
- DXY is added once when an enabled USD pair is present; removing it is honored
  on later starts and disables its endpoint.

## Data and interpretation notes

Yahoo FX is keyless and has no meaningful volume. OANDA supplies tick volume,
which is not centralized traded volume. Most pair pip sizes are 0.0001; JPY
quotes use 0.01, XAUUSD uses 0.1 and XAGUSD uses 0.01. Default spread assumptions
are 1 pip for majors, 2 for other supported crosses and 3 for metals.

FX backtests subtract spread from simulated outcomes. They do not include
swap/rollover, commissions, slippage or broker-specific execution. Yahoo native
daily/weekly candles retain Yahoo's own alignment and may not match OANDA NY-close
bars. Provider changes discard stored FX candles before collection resumes.

Paper positions preserve the source identity selected at entry (provider,
environment, mapped instrument and proxy status). A changed or unknown FX source
suspends evaluation while retaining history. Paper evaluation begins at the
first fully eligible candle after entry. Both FX backtests and paper use the
inherited optimistic TP-first choice when one candle touches both TP and SL;
the actual intrabar sequence is unknown. Paper positions show mid/reference
prices alongside execution prices. FX backtest
`EntryPrice` and `ExitPrice` record half-spread-adjusted execution prices,
while TP/SL derive from mid prices and net pips include the round-trip spread.

A 4H-only backtest cannot derive an exact Asian range. AMD marks that range
unavailable rather than inferring it from 4H bars; exact AMD range evaluation
requires hourly history. Live session overlays use 1H data even on a 4H chart.

ICT kill-zone and session windows now follow New York local time with DST. This
changes the UTC timing of kill-zone signals for every asset class compared with
the former fixed UTC windows.

## Upgrade notes

Back up settings and database before upgrading. Do not replace existing
`config/settings.yaml` or watchlists with examples. Set the Forex provider and
optional OANDA token in Settings; `auto` uses OANDA when a token is saved and
Yahoo otherwise, while `yahoo` and `oanda` select a provider explicitly. OANDA
eligibility varies by region/account; see the [Forex guide](../FOREX.md) for
general v20 information and Japan-specific requirements. A provider transition
purges Forex candles and starts a fresh backfill. OANDA practice/live selects a
market-data API environment and does not enable order execution.

## Scope limits

This release provides analysis, alerts, chart context and backtesting. It does not
place Forex orders. Swap/rollover costs and full execution costs are not modeled.
