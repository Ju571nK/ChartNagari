# v2.12.0.0 — Trading Workspace & UX Improvements

ChartNagari now connects market exploration, analysis and strategy validation in one workspace. Selecting an instrument and timeframe carries that context from the chart into analysis and backtesting, including after refresh and browser history navigation.

## Workspace and navigation

- All 16 screens are organized into Explore Markets, Validate Strategies, Manage Trades and Configuration.
- A wider desktop layout places the chart beside a signal inspector with signal context and available AI interpretation.
- Direct actions open analysis, backtesting and price alerts for the selected instrument.
- Compact screens use a grouped navigation selector; shared controls, numeric alignment and keyboard focus indicators improve readability and navigation.
- New interface labels are available in English, Korean and Japanese.

## Reliability improvements

- Obsolete chart and history requests are cancelled when their context changes.
- Failed requests are distinguished from empty results, with retry actions in affected views.
- Execution controls require a successfully loaded configuration. Failed stop/resume requests keep their confirmation open for retry.
- Price alerts are accessible from navigation and the chart inspector.
- Existing static-demo support, lazy-loaded views, hover prefetch and vendor bundle splitting are preserved.

## Validation

- Normal production build and static-demo build passed.
- Frontend: 113 tests passed. Go: `go test ./...` passed.
- CI and the GitHub Pages deployment succeeded for the merged implementation.
- Deployed-demo checks confirmed chart → analysis → backtest context continuity, price-alert navigation and compact-screen layout.

The [live demo](https://ju571nk.github.io/ChartNagari/) uses captured fixtures; it does not execute real trades. Browser release checks did not place live orders.

## Upgrade

Check out tag `v2.12.0.0` and rebuild using your existing local or Docker workflow. This release introduces no database-schema migration or new required configuration.
