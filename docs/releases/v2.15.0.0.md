# v2.15.0.0 — Forex watchlist profiles and Telegram wording

This source release adds asset-aware Forex alert defaults and optional saved
LONG/SHORT Telegram notes for each symbol. It does not include binary assets or
automatic trading.

## Forex watchlist defaults

New Forex watchlist symbols use an asset-aware default profile with ICT, SMC,
general TA and candlestick rules, score threshold 12, a four-hour cooldown and
at most three alerts per UTC day. Explicit profile selections, custom profile
definitions and spread overrides are preserved. Older profile files automatically
receive the built-in Forex profile at runtime if it is missing. Forex selection
dropdowns and the sample-data demo are localized.

## Per-symbol Telegram notes

Expand a symbol in Symbols to edit optional plain-text LONG and SHORT notes.
Choose a direction, preview it with fixed sample values, then explicitly save
or reset that direction. Preview does not use current prices and never sends a
Telegram message. Existing authentication applies to reads, saves and previews.

Templates accept English aliases (`{symbol}`, `{timeframe}`, `{direction}`,
`{entry}`, `{tp}`, `{sl}`, `{score}`, `{reason}`) and Korean aliases (`{종목}`,
`{시간봉}`, `{방향}`, `{진입가}`, `{TP}`, `{SL}`, `{점수}`, `{근거}`). Each
note is limited to 500 Unicode characters. Values are escaped before rendering.
If adding the note would exceed the conservative 4,096 UTF-16-unit Telegram
source guard, the note alone is omitted and the core alert is retained.

A saved note is appended only for its exact symbol and LONG or SHORT direction.
Unset notes, other symbols and directions, and NEUTRAL alerts retain the exact
baseline message. The notes use a separate persistent SQLite table that is
created automatically; there is no destructive database migration. Stale
preview successes and failures are discarded after edits, direction changes,
saves or symbol changes.

## Upgrade notes

Preserve your existing configuration files and database when upgrading. The
new notes table is created automatically and leaves existing configuration,
watchlists, alert overrides and stored data in place. See the [settings guide](https://github.com/Ju571nK/ChartNagari/blob/v2.15.0.0/SETTINGS.md)
for settings and migration details.
