# v2.16.0.0 — Optional Forex 15-minute data

This source release adds an opt-in Forex 15-minute data path for research. It
preserves existing watchlists, standard timeframe settings and alert behavior.
It does not enable automatic penalty calibration or order execution.

## Enable Forex 15-minute data

Choose a registered Forex symbol and **15M** in Chart, Analysis or Backtest,
then select **Enable 15M collection**. This adds 15M to the saved watchlist
timeframes for enabled Forex symbols while preserving existing symbols and
standard timeframes. Yahoo requests native `15m` candles with `range=60d`;
available history and gaps depend on Yahoo. OANDA M15 is also supported when OANDA is
configured and available to the account. OANDA collection was validated with a
mock provider in this release; this is not a claim of a live OANDA connection
test.

After enabling collection, choose **15M** in the chart, analysis, backtest or
alert timeframe controls. The chart and analysis share the selected timeframe.
The collector checks freshness at completed quarter-hour boundaries and across
weekends. The static demo's 15M candles are synthetic and labelled; they do not
represent a live or provider-verified feed.

Fifteen-minute signals use a separate Forex rule pass, which leaves existing
higher-timeframe signals in place. Fifteen-minute alerts are produced only when
15M is explicitly selected for the alert. Existing alert timeframe defaults,
score thresholds, cooldowns and daily caps are unchanged. AI prompts include the
selected timeframe and its 15M indicators only after at least 30 candles are
available. Fifteen-minute backtests require at least 202 candles to cover the
configured indicator warmup.

## USDJPY research and calibration status

This release includes offline USDJPY research scripts, a 1,440-row timeframe
comparison CSV and a reproducibility manifest. The [study report](https://github.com/Ju571nK/ChartNagari/blob/v2.16.0.0/docs/backtests/20261010_usdjpy_backtest.md)
describes the data, method and limitations. Download the [comparison CSV](https://github.com/Ju571nK/ChartNagari/blob/v2.16.0.0/docs/backtests/20261010_usdjpy_comparison.csv)
and [manifest](https://github.com/Ju571nK/ChartNagari/blob/v2.16.0.0/docs/backtests/20261010_usdjpy_manifest.json),
or use the [research tools](https://github.com/Ju571nK/ChartNagari/tree/v2.16.0.0/scripts/usdjpy-research)
to reproduce the analysis. Results were not strong enough to justify changing
default alert settings.

HTF opportunity-bucket diagnostics remain limited to 1H and 4H. This study does
not automatically calibrate HTF penalties, change alert scores or configure
orders. Automatic penalty calibration and order execution remain disabled.

## Upgrade notes

Keep your existing configuration files and database. Upgrade the source, rebuild
the frontend as usual, and restart the server. Existing watchlist symbols,
standard timeframe selections, alert settings, profiles, overrides and stored
data are preserved. Fifteen-minute collection is opt-in; enable it for the Forex
watchlist when you are ready. No configuration or database replacement is needed.

## Verification and distribution

Release validation passed `go test ./...`, `go vet ./...`, 237 frontend tests
across 33 files, the production build and five offline Python tests. Yahoo USDJPY and inverse-pair 15M history were checked for
complete candles, and a browser chart rendered 200 candles with 900-second
intervals. OANDA M15 was checked with a mock provider only. The static demo uses
synthetic labelled 15M candles. This is a source release; it contains no bundled
binaries or automatic-trading capability.
